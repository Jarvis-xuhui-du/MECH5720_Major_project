\section{Reproducibility}
The accompanying package includes the acquisition data, all 16 attempt scores, frozen selections and geometry, source hashes, reconstruction arrays, scripts, dependencies and build instructions. Run \texttt{python reproduce.py} to recalculate saved-array metrics and reproduce the paired-effect and mask figures. Reproduce all 16 RAW inversions with frozen geometry using \texttt{python reproduce.py --reconstruct}, or one coded exposure using \texttt{python reproduce.py --trial S1}. The README records the tested environment and hardware; fresh registration can vary numerically. The previous five-trial dataset is separate. Code and RAW data: \url{https://github.com/Jarvis-xuhui-du/MECH5720_Major_project/releases/tag/raw-data-v1.0}.

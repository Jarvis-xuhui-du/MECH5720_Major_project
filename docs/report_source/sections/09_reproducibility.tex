\section{Reproducibility}
The package also includes the acquisition data, scores for all 16 attempts, geometry and frozen selections, source hashes, scripts, reconstruction arrays, dependencies and build instructions. Run \texttt{python reproduce.py} to recompute saved-array metrics and regenerate the paired-effect and mask plots. Rerun all 16 RAW inversions with frozen geometry using \texttt{python reproduce.py --reconstruct}, or one coded exposure using \texttt{python reproduce.py --trial S1}. The README files record the tested software versions and hardware; fresh registration may give numerically different results. The earlier five-trial dataset is separate from the dataset analysed here.

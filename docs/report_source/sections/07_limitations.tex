\section{Limitations and Pitfalls}
The illumination history is estimated from command receipts and a fitted offset. We did not measure optical transitions with a photodetector, calibrate ranging-to-receipt delay or measure rolling-row skew. The tested timing perturbations cover only selected errors.

The scale model also omits continuous tilt, lateral drift, depth-dependent defocus and spatial variation in illumination. Our fixed-focus controls show that sharpness changes even within the retained range. The optical origin remains uncertain, and the 22\,mm base-to-paper offset provides no independent sensor-bias calibration. These effects were not separated experimentally, so we cannot assign either failed comparison to a single physical cause.
